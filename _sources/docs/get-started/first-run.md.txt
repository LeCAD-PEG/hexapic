# First run

This page runs the two-stream instability. Two electron beams move in
opposite directions through stationary ions in a periodic box. The case is
defined by a PICMI script in `examples/basic_plasma/two_stream/`.

## Write the case

The script takes a directory and writes `case.toml` into it:

```bash
python/.venv/bin/python examples/basic_plasma/two_stream/case.py runs/twostream
```

The result, `runs/twostream/case.toml`, is a plain TOML file. Here is a
shortened version:

```toml
format_version = 1
title = "two_stream_ee_es"

[grid]
cells = [256, 8]
lower = [0.0, 0.0]
upper = [6.785863209393971e-06, 2.1205822529356158e-07]
periodic = [true, true]

[time]
dt = 5.623042841679827e-16
steps = 2000

[[species]]
name = "electrons"
mass = 9.1094e-31
charge = -1.6022e-19

[[species]]
name = "ions"
mass = 6.646485633287956e-27
charge = 1.6022e-19
subcycle = 10

[[load]]
species = "electrons"
density = 5e+23
weight = 8.78294744426854e+07
thermal_speed = [30000.0, 0.0, 0.0]
drift = [1e+07, 0.0, 0.0]
same_positions_as = "ions"
```

The second beam is another `[[load]]` of the same species with the opposite
drift. A third `[[load]]` adds the ions at twice the density. Both beams start
on the ions' positions, so there is no charge at the start and the
instability grows from a low noise. All keys are
described in the [`case.toml` reference](../user-guide/case-toml.md).

## Run it

Check the case first. The `--check` option reads the case and sets it up on
the host. It does not need a GPU, so it also works on a login node.

```bash
build/HEXAPIC runs/twostream/case.toml --check
```

```text
[Input] runs/twostream/case.toml: ok (3 population(s), 256 x 8 cells)
```

Then run it:

```bash
build/HEXAPIC runs/twostream/case.toml
```

The case runs 2000 steps. On one A100 this takes about six seconds. The
script can also start the run itself: add `--run` to its command. The run prints its setup, then its progress,
and at the end the time per step.

## Look at the output

The output is written next to the case, into `runs/twostream/output/`:

| File | Contents |
|---|---|
| `hexapic.bp` | The openPMD series. It holds the fields, the moments and the phase spaces of each species every 10 steps, and the particles at the first and the last step. |
| `hexapic_used.toml` | The case as it ran, with every key written out. |

Open the run in the [HEXAPIC viewer](../visualization/index.md):

```bash
python tools/viz/hexapic_viz.py runs/twostream
```

The x–vx phase space of the electrons shows the two beams and the instability
that grows out of them.
