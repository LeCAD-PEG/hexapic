# Visualization

HEXAPIC / VIZ shows a run in the browser. It displays the fields, the moments
and phase spaces of each species, profiles, probes and the energies. You can
step through the run on a timeline, play it back, and export images and
videos. The viewer reads the openPMD series of a finished run, or the frames
that a running simulation writes. It serves them from the machine where the
run is stored.

```{figure} ../_static/images/examples/hall_thruster_app.png
:name: fig:viz-app
:width: 100%
:figclass: hx-shot

The {site}`3-D Hall thruster <examples/gen/hall_thruster_3d>` in HEXAPIC / VIZ at
the last step of the run. The views show the ion density as an isosurface
and in the middle plane, the phase space of the ions, and the energies.
```

Start the viewer on a run and open `http://localhost:8080` in your browser:

```bash
python tools/viz/hexapic_viz.py runs/twostream
```

A few things to know about the viewer:

- You arrange the views as in an IDE. Views can be split, stacked and
  resized, and you can open as many of each kind as you need.
- Images are drawn with WebGL2 and plots with Observable Plot. All libraries
  are included in the repository, so the viewer also works on clusters where
  the compute nodes have no internet access.
- A step is drawn in a few milliseconds. The server prepares the frames once,
  and the app loads all steps of the displayed quantities in the background.
