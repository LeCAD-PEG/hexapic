# Performance

HEXAPIC keeps the particles and the fields on the GPU for the whole run. The
host enqueues the work of a step on several GPU queues and waits only where
it needs a result. The field solve is usually the only stage that couples
the whole domain. HEXAPIC uses a multigrid solver written for this setting,
described in [GMGa3](../solvers/gmga3.md).
