# Starting the viewer

```text
python tools/viz/hexapic_viz.py [<directory of runs, or a run>] [--port 8080] [--host 127.0.0.1]
```

The viewer needs the Python packages `numpy` and `openpmd-api`. To export
videos it uses `ffmpeg` on the server. Without `ffmpeg` the browser records
the video itself and may drop frames.

## Opening a run

If you pass a run, the viewer opens it directly. A run can be given as its
directory, its output directory or its `.bp` file:

```bash
python tools/viz/hexapic_viz.py runs/twostream
```

## The explorer

Without a run, the viewer starts in an explorer that lists a directory. The
default is `runs/` at the top of the repository, which git ignores. Each row
is either a run or a directory that you can enter.

The row of a run shows its dimension, cells, steps and number of outputs,
taken from its `hexapic_used.toml`. It also shows whether the frames are
built, the size of the run and its age. Click a row to open the run. The
address of an open run, `?run=<path>`, can be bookmarked. The name of the run
in the header takes you back to its directory.

The viewer recognises a directory as a run if it contains an openPMD series
(`*.bp`) or live frames, either directly or in its `output/` subdirectory.

## On a cluster

The server listens on `127.0.0.1` of the node where it runs. To reach it from
your laptop, open an SSH tunnel. The server prints the command when it
starts:

```bash
ssh -L 8080:localhost:8080 <node>
```

If the node is not the login node, add `-J <login node>`. Then open
`http://localhost:8080` in your browser.

To listen on every network interface instead, start the server with
`--host 0.0.0.0`.
