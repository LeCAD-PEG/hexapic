# Examples

```{rst-class} hx-lead
```

Complete cases that run as they are. Each page gives the setup of a case,
the commands that run it and its results. Where there is something to
compare with, the results are set against theory, against other codes or
against published benchmarks.

The cases are in the `examples/` directory of the code, grouped by their
physics. The pages here are built from the files there, so the commands and
the numbers on them are the ones in the repository.
