# Tutorials

The tutorials teach HEXAPIC by doing. Each one builds a case from scratch,
runs it and looks at the result. Exercises along the way have their
solutions folded below them. The tutorials assume that the code is built, as
described in {doc}`Installation <../docs/get-started/installation>`, and
that you have a GPU.

Each tutorial states what you will be able to do at the end, how long it
takes and what it needs. Type the steps yourself as you read. Every command
on these pages was run exactly as shown.

:::{note}
The first tutorials are being written. Until they are published, the only
walk-through is {doc}`First run <../docs/get-started/first-run>`. The
{doc}`examples <../examples/index>` are complete cases that you can start
from.
:::
