# Development

The source code is in `source/`:

| Directory | Contents |
|---|---|
| `main.cpp`, `pic/` | The PIC loop |
| `kernels/` | The kernels |
| `solvers/` | The field solvers |
| `input/` | The case reader |
| `io/` | The output |

Every kernel is written once as an alpaka3 kernel. Where 2-D and 3-D differ,
the kernel is a template on the dimension.
