# Documentation

```{rst-class} hx-lead
```

HEXAPIC, the Heterogeneous Exascale Particle-In-Cell code, is an
electrostatic particle-in-cell code with Monte Carlo collisions for bounded
plasmas. It runs in 2-D and 3-D on NVIDIA and AMD GPUs from a
single [alpaka3](https://github.com/alpaka-group/alpaka3) source.

These pages are the reference. They explain how to build the code, how to
describe a case, what a run writes and how the code computes. If you are new
to HEXAPIC, start with [First run](get-started/first-run.md). For complete
cases, see the {site}`examples <examples/index>`.
