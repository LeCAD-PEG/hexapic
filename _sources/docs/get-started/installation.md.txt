# Installation

HEXAPIC is built with CMake. The build downloads alpaka3, ADIOS2 and
openPMD-api from GitHub, so the machine needs network access when you
configure for the first time. toml++ is included in the repository. You also
need a GPU toolchain and MPI.

## Requirements

| | |
|---|---|
| CMake | 3.25 or newer |
| C++ compiler | C++20 |
| GPU toolchain | CUDA for NVIDIA, or ROCm/HIP for AMD |
| MPI | Any implementation. GPU-aware MPI is not required. |
| Python | 3.11 or newer. Optional, used by the [PICMI](../user-guide/picmi.md) scripts and the [viewer](../visualization/index.md). |

## Build with a preset

If the GPU toolchain and MPI are already in your environment, clone the
repository and run the `default` preset. It configures the project and builds
it into `build/`:

```bash
git clone --branch alpaka3 git@bitbucket.org:lecad-peg/hexapic.git
cd hexapic
cmake --workflow --preset default
```

The `default` preset detects the GPU toolchain, which can be CUDA, HIP or
SYCL. With CUDA it builds for the GPU of the node you build on. If that node
has no GPU, set the target architecture yourself:

```bash
cmake --preset default -DCMAKE_CUDA_ARCHITECTURES=80 && cmake --build build -j
```

The executable is `build/HEXAPIC`. To check that it works, print its help:

```bash
build/HEXAPIC -h
```

## Build on a cluster

Each cluster that HEXAPIC runs on has its own preset. It also has a file that
loads the modules needed to build and to run, `tools/machines/<name>.sh`. The
script `tools/build.sh` loads these modules and builds into `build-<name>`:

```bash
tools/build.sh lumi
```

| Preset | Machine | GPU |
|---|---|---|
| `hpcfs` | HPC-FS (Ljubljana) | NVIDIA A100 |
| `vega` | VEGA (IZUM) | NVIDIA A100 |
| `lumi` | LUMI-G (CSC) | AMD MI250X |
| `pitagora` | Pitagora (CINECA) | NVIDIA H100 |

To use another build directory or to pass CMake options, add them after the
machine name:

```bash
tools/build.sh lumi build-lumi-cic -DHEXAPIC_SHAPE_ORDER=1
```

In a job script, source the same module file before the run:

```bash
source tools/machines/lumi.sh
srun build-lumi/HEXAPIC case.toml
```

On a machine without access to GitHub, the build takes alpaka3 from
`offline-deps/alpaka3-src` if that directory exists.

## Build options

Some properties are fixed at compile time: the floating-point precision, the
particle shape, the number of dimensions and the GPU back end. You set them
with CMake options, which are described in
[Build options](../user-guide/build-options.md).

## The Python tools

The PICMI scripts and the case generators use the Python package
`hexapic.picmi`. Install it once per machine in a virtual environment:

```bash
python3 -m venv python/.venv
python/.venv/bin/pip install -e python/
```

The module files of the clusters activate `python/.venv` if it exists. The
[viewer](../visualization/index.md) needs only `numpy` and `openpmd-api`.
