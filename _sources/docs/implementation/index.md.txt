# Implementation

HEXAPIC is an electrostatic PIC code with Monte Carlo collisions, and it uses
the standard methods. These pages do not repeat the textbook. The table
lists the methods and where they come from.

| Part | Method | Reference |
|---|---|---|
| Push | Leapfrog. With a magnetic field, the Boris rotation. | {cite:p}`boris1970` |
| Shape | CIC (linear) or TSC (quadratic), the same for deposit and gather | {cite:p}`hockney1988` |
| Field | $-\nabla\cdot(\varepsilon\nabla\phi) = \rho$ on a five-point stencil, seven-point in 3-D, with $\mathbf{E} = -\nabla\phi$ at the nodes | |
| Collisions with a gas | Monte Carlo with null-collision selection | {cite:p}`vahedi1995` |
| Coulomb collisions | The cumulative model of Nanbu, or the binary model of Takizuka and Abe | {cite:p}`nanbu1997`, {cite:p}`takizuka1977` |

The following pages describe the parts that are specific to HEXAPIC, and the
choices that can change a result. They cover how a step runs on the GPU, the
details of the collisions, and the walls and objects. The field solvers have
their own section, [Solvers](../solvers/index.md).
